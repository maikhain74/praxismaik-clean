# PraxisMaik Roadmap

Version: 1.0

Diese Roadmap beschreibt die langfristige Entwicklung von PraxisMaik.

Sie dient als Orientierung für zukünftige Entscheidungen und wird kontinuierlich erweitert.

---

# Vision

PraxisMaik wird die qualitativ beste deutschsprachige Lernplattform für die generalistische Pflegeausbildung.

Der Schwerpunkt liegt nicht auf der größten Anzahl an Inhalten, sondern auf der höchsten Qualität, der besten Nutzerführung und einem echten Mehrwert für Pflegeazubis und Pflegefachpersonen.
