# Aspiration

Bei einer Aspiration gelangen Nahrung, Flüssigkeit oder Erbrochenes in die Atemwege.

Dadurch kann die Atmung gefährlich beeinträchtigt werden.

## Warum Aspiration wichtig ist

Eine Aspiration kann schnell lebensbedrohlich werden.

Besonders gefährdet sind Menschen mit:

- Schluckstörungen
- Bewusstseinsstörungen
- neurologischen Erkrankungen
- Erbrechen

## Typische Warnzeichen

Mögliche Hinweise sind:

- plötzlicher Husten
- Atemnot
- rasselnde Atmung
- Würgen
- veränderte Stimme
- Angst oder Unruhe

Nicht jede Aspiration ist sofort offensichtlich.

## Pflegerischer Blick

Wichtig ist:

- ruhig bleiben
- Atmung beobachten
- Oberkörper hoch lagern
- Hilfe organisieren
- Risiken früh erkennen

Vorbeugung spielt in der Pflege eine große Rolle.

## Merke

> Husten und Atemprobleme beim Essen sind immer ein Warnsignal.
