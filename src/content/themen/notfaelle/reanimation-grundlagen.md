# Reanimation Grundlagen

Eine Reanimation wird durchgeführt, wenn Atmung und Kreislauf ausfallen.

Dann zählt jede Sekunde.

## Warum Reanimation wichtig ist

Ohne schnelle Hilfe wird das Gehirn innerhalb weniger Minuten geschädigt.

Deshalb müssen Notfallsituationen schnell erkannt werden.

## Typische Hinweise

Mögliche Zeichen sind:

- keine Reaktion
- keine normale Atmung
- Bewusstlosigkeit
- fehlende Lebenszeichen

Dann muss sofort gehandelt werden.

## Pflegerischer Blick

Wichtig ist:

- Bewusstsein prüfen
- Atmung kontrollieren
- Hilfe holen
- Reanimation beginnen
- ruhig und strukturiert arbeiten

Teamarbeit spielt eine große Rolle.

## Merke

> Keine normale Atmung plus Bewusstlosigkeit bedeutet Reanimationspflicht.
